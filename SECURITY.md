# Security Policy

EverNest holds families' most sensitive documents, so we take reports seriously.

## Reporting a vulnerability

**Please don't open a public issue.** Report it privately through this repository's [Security tab](https://github.com/aryanpol73/evernest/security/advisories/new).

Please include:

- What the problem is and what an attacker could do with it
- Steps to reproduce it
- The affected page, API, or file

We aim to acknowledge reports within 3 working days.

## Testing rules

- Use only accounts and data you created yourself
- Never access, change, or delete another person's data, even to prove a problem exists
- Don't run denial-of-service attacks, automated scanning at volume, or social engineering

## Scope

In scope: this repository, and the EverNest application and its database access rules.

Out of scope: vulnerabilities in third-party services, which should go to those providers, and reports with no demonstrated security impact.
